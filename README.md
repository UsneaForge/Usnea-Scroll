# Usnea Scroll

Write a phrase and share the link. Whoever receives it can navigate the same procedurally generated maze to discover it, letter by letter.

No account. The maze is encoded entirely in the URL.

**Play it at [usnea-scroll.com](https://usnea-scroll.com)**

## How it works

1. **Compose** — write a message (up to 250 characters) and choose a canopy difficulty
2. **Cast** — generates a shareable link
3. **Play** — the recipient navigates the maze, finding words in the clearings

The message authors the maze. Same message, same maze, everywhere.

## Running it locally

Open `index.html`. That's it.
